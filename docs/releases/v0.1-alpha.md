# v0.1-alpha

Date: 2026-05-20

Status updated: 2026-07-12

This alpha is the first end-to-end Urbanization Tracker checkpoint for the Huntsville pilot.

## Included

- FastAPI backend, React/Vite frontend, Docker Compose, Postgres/PostGIS scaffolding, and Redis.
- MapLibre map with development records, environmental overlays, filters, detail pages, source links, confidence labels, and caveats.
- Huntsville ArcGIS ingestion for New Subdivisions, Building Permits, FEMA 1% floodplain, and mapped wetlands.
- Planning Commission agenda PDF ingestion with stored PDFs, extracted text, source documents, staged candidates, and duplicate signals.
- Reviewer queue for approving, rejecting, or marking records as needs-info.
- Public submissions, watch areas, queued email-channel alerts, record versions, and change log.
- Jurisdiction/source config registry with Huntsville plus a live Madison County subdivision source
  and an inactive demo onboarding fixture.
- Connector health dashboard, reviewer decision import/export, source onboarding docs, privacy/safety checklist, and performance smoke tests.

## Known Alpha Boundaries

- Runtime data artifacts in `data/` are generated locally and intentionally ignored by git.
- Alerts support bounded SMTP delivery, but production delivery remains disabled until provider
  credentials and end-to-end operational behavior are verified.
- Proximity calculations use screening-level local geometry intersection and distance checks; the
  normalized durable model should eventually use PostGIS spatial predicates.
- Review, submission, watch-area, alert, and canonical processed collections can use Postgres, but
  each deployed environment must run the artifact-to-database migrations before switching stores.
- Raw PDFs, raw ArcGIS payloads, and extracted text remain local artifacts until durable object
  storage and mirroring are configured; the artifact manifest records hashes and intended storage
  URIs but does not itself upload files.
- Madison County subdivisions are available through a live ArcGIS connector. A separate inactive
  Madison County demo fixture remains only as an onboarding example.
- The repository contains a Render Blueprint and production preflight command, but a public hosted
  deployment has not been verified from this workspace.
- The latest local ingestion snapshot was captured on 2026-06-19 and must be refreshed before it is
  used as current public data.
