# v0.1-alpha

Date: 2026-05-20

This alpha is the first end-to-end Urbanization Tracker checkpoint for the Huntsville pilot.

## Included

- FastAPI backend, React/Vite frontend, Docker Compose, Postgres/PostGIS scaffolding, and Redis.
- MapLibre map with development records, environmental overlays, filters, detail pages, source links, confidence labels, and caveats.
- Huntsville ArcGIS ingestion for New Subdivisions, Building Permits, FEMA 1% floodplain, and mapped wetlands.
- Planning Commission agenda PDF ingestion with stored PDFs, extracted text, source documents, staged candidates, and duplicate signals.
- Reviewer queue for approving, rejecting, or marking records as needs-info.
- Public submissions, watch areas, queued email-channel alerts, record versions, and change log.
- Jurisdiction/source config registry with Huntsville plus a Madison County demo source.
- Connector health dashboard, reviewer decision import/export, source onboarding docs, privacy/safety checklist, and performance smoke tests.

## Verification

- `make lint`
- `make typecheck`
- `make test`
- `make build`
- `npm --workspace apps/web run e2e`
- Docker stack verified locally at `http://127.0.0.1:5173`.

## Known Alpha Boundaries

- Runtime data artifacts in `data/` are generated locally and intentionally ignored by git.
- Alerts are queued as email-channel records; SMTP/provider delivery is not wired yet.
- Phase 2 proximity calculations are screening-level local geometry checks; exact normalized-table
  PostGIS spatial methods should replace them later.
- Review, submission, watch-area, and alert persistence currently uses local artifacts over the scaffolded database models.
- The Madison County source is a demo onboarding fixture, not a live public source.
