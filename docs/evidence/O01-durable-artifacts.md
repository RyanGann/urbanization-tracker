## Retention and recovery contract

The manifest records immutable run references and content-addressed blobs. There is no automatic deletion of verified objects or manifest rows in O01; operators must retain any object referenced by a published or auditable run. Local staging is a retry cache, not a backup, and may be removed only after the corresponding object copy is verified. This PR does not set a production retention period or enable hosted ingestion.

Restore the PostgreSQL database and the private object collection as one matched recovery set. Configure the restored sink identity, copy or restore each referenced object, then stream and hash each required object against the manifest before allowing new publication. A database-only backup is insufficient: it can preserve references whose bytes no longer exist. The isolated `o01-artifacts` scenario exercises this with a copied database and a second private Garage bucket; it does not constitute a production backup policy or cloud-provider choice.
