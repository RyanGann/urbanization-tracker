# O04 source-use inventory — decision draft

Checked 2026-09-24 UTC against the linked primary pages and the `38ebf7c` source configuration. This records evidence and proposed release gates, **not** permission or a legal conclusion. Recheck the exact service metadata and terms at launch. A public endpoint, downloadable file, or blank ArcGIS `copyrightText`/`licenseInfo` does not establish permission to rehost its contents. Code licensing, dataset rights, and hosted map-service terms are separate decisions.

`private staging` below means the project's intended access control for audit and validation; it is not a finding that any source's terms authorize indefinite storage. No listed third-party dataset is cleared here for public geometry tiles, bulk download, or inclusion in this repository. Keep retrieval/checksum/version provenance, restrict raw storage to operators, and set a retention period after the owner selects the source-use path. [O04 decision sheet](O04-release-decisions.md) assigns the remaining choices.

## Basemap and generated assets

The current `DevelopmentMap.tsx` style contains only an application-colored background with **no external basemap requests**. Its compact attribution control says “Seed data for planning MVP”; it is not attribution for a real basemap. No hosted basemap provider has been selected or accepted for production.

U02 proposes a configurable [OpenFreeMap Liberty](https://openfreemap.org/) style. The [OpenFreeMap service page](https://openfreemap.org/) checked 2026-09-24 says its public instance needs no account/API key and permits commercial interactive use with OpenMapTiles/OpenStreetMap attribution. Its [Terms of Service](https://openfreemap.org/tos/) (last updated 2026-09-09) prohibit unauthorized automated collection, offer no availability guarantee and refer to [its privacy policy](https://openfreemap.org/privacy/), including CDN handling. [OSM data attribution and ODbL](https://www.openstreetmap.org/copyright) remain separate from OpenFreeMap software's MIT license. Do not cache/archive a hosted tile corpus or copy someone else's basemap assets. Confirm the exact style's rendered mobile attribution and third-party request/privacy behavior before selecting it. If unavailable, the application should show its own no-basemap background plus records and a visible provider-error state, without silently substituting [OSMF's standard raster tiles](https://operations.osmfoundation.org/policies/tiles/), which have separate usage limits.

## Control and retention record required before public activation

For each stable ID and each direct-federal replacement, record `producer`, `serving_host`, exact service/dataset URL, retrieved terms URL/date and metadata checksum, `attribution`, source and spatial scope/version, `private_storage_basis`, `public_record_display`, `public_geometry_tiles`, `bulk_export`, `retention_period`, and `decision_owner/date/evidence`. Each public-use field should start `unresolved`, never inherit a decision from another source or from a code license. The publication/export path needs an enforced allowlist or equivalent fail-closed gate keyed to the exact version and use; a document flag alone does not prevent the current legacy API from serving geometry. Reassess cached versions and downloadable artifacts when a decision changes.
